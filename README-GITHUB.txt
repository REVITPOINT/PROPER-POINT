PROPER POINT — wersja do GitHub Pages

1. Otwórz repozytorium GitHub.
2. Wybierz Add file > Upload files.
3. Rozpakuj ZIP na komputerze i wgraj wszystkie pliki oraz foldery do głównego katalogu repozytorium (index.html ma być na głównym poziomie).
4. Commit changes.
5. Settings > Pages > Deploy from a branch > main > /(root) > Save.
6. Odwiedź https://TWOJ-LOGIN.github.io/NAZWA-REPOZYTORIUM/

To statyczna wersja strony z dostarczonego archiwum. Zachowano obrazy, układ, style, skrypty i podstrony. GitHub Pages nie wykonuje reguł z .htaccess, dlatego nie dołączono tego pliku.
Uwaga: linki do aktualnej domeny properpoint.pl w metadanych SEO oraz sitemap.xml pozostały bez zmian; w razie użycia innej domeny docelowej należy je zaktualizować.
